# Тестовое задание АНО Национальное Агентство Мониторинга и Статистики

Проект реализует интерфейс для сопоставления **платежей** и **счетов**.  
Основная цель — предоставить бухгалтеру удобный инструмент для ручной привязки платежа к счету.

_Сопоставление выводится в консоли:_

```bash
Сопоставление: 
Object {invoiceId: "101", paymentId: "1"}
```

Если платёж сопоставлен с несколькими счетами, для каждого счёта выводится отдельная запись.

---

## Возможности
- Выбор одного платежа и одного или нескольких счетов кликом по строке или по переключателю
- Поиск платежей по заказчику и счетов по ФИО экзаменуемого
- Постраничный вывод таблиц, выбор сохраняется при поиске и смене страницы
- Сводка по выбранным записям и сумме счетов в форме сопоставления
- Отметка сопоставленных записей и запрет их повторного сопоставления
- Открывающаяся консоль в интерфейсе с кнопкой очистки: результаты сопоставления видны без DevTools

Сопоставление выполняется, если:
- сумма выбранных счетов равна сумме платежа
- ИНН заказчика во всех выбранных счетах совпадает с ИНН заказчика в платеже

Бэкенда нет, данные берутся из `src/constants`, поэтому отметки о сопоставлении сбрасываются при перезагрузке страницы.

## Запуск
```bash
npm install
npm run dev
```

| Команда | Описание |
|---|---|
| `npm run dev` | Запуск в режиме разработки |
| `npm run build` | Проверка типов и сборка в папку `docs` |
| `npm run preview` | Просмотр собранной версии |
| `npm run lint` | Проверка кода линтером |

## Стек технологий
- Vite + TypeScript
- React
- React Hook Form — отправка формы и ошибки валидации
- MUI (Material UI) — таблицы, поля ввода, кнопки
- CSS Modules для оформления

## Структура проекта
```bash
├── index.html
├── docs // Собранная версия для GitHub Pages
├── public
│   └── .nojekyll // Отключает обработку Jekyll на GitHub Pages
└── src
    ├── app
    │   ├── App.tsx // Главная страница
    │   └── main.tsx // Точка входа
    ├── components
    │   ├── index.ts // Экспорт компонентов
    │   ├── InvoiceTable.tsx // Таблица счетов
    │   ├── PaymentTable.tsx // Таблица платежей
    │   ├── MatchForm.tsx // Форма сопоставления
    │   └── MatchConsole.tsx // Консоль сопоставлений
    ├── constants
    │   ├── index.ts // Экспорт констант
    │   ├── invoice.ts // Тестовые счета
    │   ├── payment.ts // Тестовые платежи
    │   ├── matchLog.ts // Настройки консоли
    │   └── table.ts // Настройки таблиц
    ├── hooks
    │   └── usePaginatedSearch.ts // Поиск и пагинация
    ├── style
    │   ├── App.module.css // CSS Modules
    │   ├── App.css.d.ts // CSS декларации для TS
    │   └── index.css // Глобальные стили
    └── types
        ├── invoice.ts // Типы счетов
        ├── payment.ts // Типы платежей
        └── matchLogEntry.ts // Тип записи консоли
```
